# 复盘日历 Phase 0 回测报告（冰点 + 3 态周期状态机）

> 数据窗口：2016-05-06 → 2026-08-26，2505 个交易日（daily_bars 1080 万行物化）。
> 结论：两条规则都**可用**，但都**必须按我们自己的口径标定阈值**，不能照抄 fupanhui 数值。

## 2. 冰点规则验证结论

### 2.1 口径差异（重要）
- 我们的涨跌家数与 fupanhui 完全一致（如 2026-08-03：4005/1466）。
- 但全市场成交额有约 **0.7% 差异**：我们 SUM(daily_bars.amount) 含北交所，fupanhui 疑似只用沪深两市。
- 后果：边界日会分级不同——2026-08-03 我们算量能比 0.7773（<78% → 极冰），fupanhui 算 0.7939（接近冰点）。
- **结论：78%/85% 阈值必须用我们自己的口径重新标定，不能直接抄。**

### 2.2 冰点前瞻收益（10 年，上证）
| 等级 | 其后5日均值 | 其后5日胜率 | 其后20日均值 | 其后20日胜率 | 样本 |
|---|---|---|---|---|---|
| 极冰（量能比<78%） | +0.65% | 65.7% | +0.66% | 58.5% | 201 |
| 接近冰点（78~85%） | -0.14% | 52.3% | -0.31% | 45.7% | 258 |
| 偏冷（85~100%） | -0.19% | 47.1% | +0.05% | 48.6% | 870 |
| 无（≥100%） | +0.25% | 55.7% | +0.66% | 55.4% | 1175 |

- **极冰是有效的反弹信号**；**接近冰点不是**（甚至负向）。
- 阈值敏感性单调：量能比越低，其后 5 日胜率越高（<0.72 时 74.2%，<0.78 时 66.0%，<0.86 时 57.4%）。
- **建议**：对外保留「极冰 / 接近冰点」两档事实标签；但产品内做「冰点前瞻」时只把「极冰」当有效观察，接近冰点仅作信息展示。

## 3. 周期状态机（3 态）验证结论

### 3.1 规则（已修正方向 bug）
- 活跃：量能比 ≥1.0 且 上涨家数占比 ≥55%。强确认：量能比 ≥1.2 且占比 ≥55%。
- 收缩：量能比 ≤0.85 或 上涨家数占比 ≤35% 或 上证跌 ≤-2%。强确认：上证跌 ≤-2.5% / 量能比 ≤0.7 / 占比 ≤20%。
- 震荡：其余。滞回 N 日（连续满足才切换），仅相邻跳转。
- ⚠️ 第一版把「量能比 ≥1.2 单日」当活跃强确认，导致 2024-01-22 恐慌放量日（-2.68%）被误标活跃；已改为「放量 + 涨家数占优」才活跃。

### 3.2 回测结果（hysteresis=5）
- 状态分布：收缩 26.4% / 震荡 65.0% / 活跃 8.5%；平均 4.4 交易日切换一次。
- 定性抽检：2024-01 恐慌期标收缩 ✓、2024-02 微盘危机→反弹标收缩→活跃 ✓、2024-09-24 暴涨精准切活跃 ✓、2026-08 震荡市标震荡 ✓。
- 状态 → 其后 5 日上证：活跃 +0.42%（胜率 54.7%）、收缩 +0.44%（胜率 60.9%）、震荡 -0.10%（胜率 49.8%）。
- 含义：活跃=动量延续、收缩=超跌反弹，**震荡才是无方向的真空区**。三态有区分度，够用，无需上 6 态。
