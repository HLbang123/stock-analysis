# 预警规则说明

> 本文档是现有预警规则的人工参考说明。规则的**代码事实源**是 [services/alertRules.ts](../services/alertRules.ts)，**AI prompt 注入源**是 [services/deepAnalysisPrompt.ts](../services/deepAnalysisPrompt.ts) 的 `RULES_TABLE`。本文档供维护时阅读，若与代码不一致以代码为准。

共 **14 条**规则。卖出侧合并为两个**阶梯规则**（R01 见顶阶梯、R02 离场阶梯），同类信号在一个阶梯内按严重度择优，**杜绝"一条清仓一条减仓"的跨规则矛盾预警**。买入侧各信号独立触发（叠加确认，不做择优阶梯），预警页按触发数量+可信度聚合为「买入共振强度档位」。

## 卖出侧：两个阶梯规则

### R01 见顶阶梯

把所有"见顶/过热/量能出逃"信号合并到一个阶梯。一只票最多出一条见顶预警，主信号 = 触发里严重度最高者；**extraData 列出全部命中的子信号**（`{ main, triggered: [...] }`），供 UI 展示。

| 子信号 | 严重度 | 强度 | 说明 |
|---|---|---|---|
| 对子顶 | 5 | 强卖出 | 高/收接近+上影+放量，双顶成型 |
| 巨量见顶 | 4（量比≥4x 升 5） | 强卖出 | 高位+量比≥2x20日均量+滞涨/阴线/长上影派发确认；≥4x 十年回放 T+5 胜率仅33%、均值-2.34% |
| 第二波见顶 | 4 | 强卖出 | 近期量≥第一波高潮×0.9 |
| 涨停炸板 | 4 | 强卖出 | 触及涨停价后回落开板，强势终结 |
| RSI超买新高 | 2 | 弱提醒 | 价格创新高 + 前摆动高 RSI(14)≥70，短期过热 |
| 巨量异动 | 1 | 关注 | >5日均量×1.20（已成交量口径不折算） |
| ~~跳空衰竭/纺锤线~~ | — | 已删 | 08-15 生产胜率：T+5 均值 +0.09%/+0.06% 为正=纯噪声 |
| ~~长上影/长下影见顶~~ | — | 已删 | 08-17 十年全市场回放：长上影 T+5 +0.81% 反向、长下影 +0.14% 无效 |
| ~~涨停封板~~ | — | 已删 | 08-17 十年回放 T+5 +1.48%——封板是强势延续不是见顶 |

**涨停判定**：按代码前缀取涨跌幅比例——创业板(30x)/科创板(688)=20%、ST=5%、其余主板=10%；涨停价=`round(昨收×(1+比例),2)`。当日最高≥涨停价且收盘回落开板=`涨停炸板`(4级，强卖出)。`quote` 缺失时按主板10%兜底。

### R02 离场阶梯

把所有"破位/离场"信号合并到一个阶梯。一只票最多出一条离场预警，主信号 = 严重度最高者；**extraData 列出全部命中的子信号**。10日线为卖出主线，买入仍看 5/13 金叉（R04）。

| 子信号 | 严重度 | 强度 | 说明 |
|---|---|---|---|
| 急跌 | 5 | 最强卖出 | 单日跌幅>7% |
| 5/13死叉 | 4/2 | 破55日线强卖出 / 站上55日线弱提醒 | MA5下穿MA13；同步破55日线=下跌中继，站上55日线=回调假死叉 |
| 5/10死叉 | 4 | 强卖出 | MA5下穿MA10，短期反转 |
| 破趋势线+破MA60 | 4 | 强卖出 | 破10日低点趋势线+破MA60，牛熊分界 |
| 有效跌破10日线 | 3 | 卖出 | 连续两日收<MA10，破后未收回 |
| 跌破5日线 | 2 | 弱提醒 | 近2根内下穿MA5 + 放量 |
| 破趋势线 | 2 | 弱提醒 | 破10日低点趋势线+放量（未破MA60） |
| 跌破10日线待确认 | 1 | 弱提醒 | 当根收<MA10 且 前根收≥MA10（刚破） |
| ~~放量离场/缩量破位~~ | — | 已删 | 08-05 回测：无区分度/反向信号 |

**破位两段式**（用户决策）：实时系统"次日"数据未到，用"连续两日未收回"作有效破位的实时近似——当根跌破先提示「待确认」，下一根仍未收回站上才升级「有效跌破」。

### 其他卖出规则
- **R03 跌破55日线**：收盘下穿MA55，进入非多头区域，大势信号（非仓位指令）。

## 买入侧（R04-R12）

买入信号各自独立触发，不择优；多个信号同时触发属**叠加确认**，预警页据此聚合出「买入共振强度档位」。

- **R04 5/13金叉**：MA5 上穿 MA13；放量+站上55日线→强买(A级)，否则谨慎(B级)。
- **R05 5/10金叉**：MA5 上穿 MA10；放量确认短线启动，与 R04 同时出现属多重确认。
- **R06 止跌企稳**：抛压释放(>10%) + 新低区锤子线(下影≥实体×2 + 下影>2% + 上影<1%) 或 十字星。
- **R07 RSI超卖**：RSI(6)<20 超卖；强下行趋势（MA20 下行 + 收盘破 MA20）中过滤不报，避免接飞刀。
- **R08 反包入场**：15日回调>5% + 涨≥5% + 收>98%近期高。
- **R09 黄金位反弹**：回调至0.382-0.618 + 涨>3% + 放量×1.2。
- **R10 箱体信号**：40日箱体突破(>3%+放量)优先，或60日箱体放量小阳吸筹。
- **R11 均线多头排列**：MA5>MA10>MA13 + 股价站上MA55，且多头排列刚刚形成（近2根内 MA5上穿MA10 / MA10上穿MA13 / 价格上穿MA55）；放量(量比≥1.2)确认多头格局，缩量为弱势多头需确认。
- **R12 站稳五日线**：连续3日收盘站上MA5 + MA5上行 + 站稳刚刚形成（站稳前一日在MA5之下，避免上行趋势中每日重复触发；且站稳前数日非大幅高于MA5，过滤从高位跌回五日线的假站稳）。量价配合：温和放量(量比1.0~1.8)量价配合好；暴量(>1.8)注意赶顶不追；缩量确认度一般。强势确立信号。

## 参考级弱提醒（R08/R11/R13/R14）

不参与买入共振硬聚合，仅作展示提示。

- **R08 反包入场**：回调后放量反包突破（08-17 移入参考级：十年全市场回放 T+5 胜率 41.8%/均值 -0.22%，负 alpha）。
- **R11 均线多头排列**：MA5>MA10>MA13+站上MA55 刚形成（08-17 移入参考级：十年回放 T+20 均值 -0.66%，多头刚确立≈局部顶；同由 5/13/55 改 5/10/13 提升短期灵敏度）。
- **R13 筹码低位密集**：90%集中度<0.18 + 获利盘>60% + 主峰接近/低于现价，结构偏多。
- **R14 筹码高位套牢**：获利盘<40% + 主峰高于现价5% + 20日涨幅>15%，上方套牢盘重。

## 统一 K 线形态定义（`classifyCandle`）

用**影线/实体比**定义，长上影/长下影与纺锤线互斥。形态本身方向中性，是顶部还是底部信号由调用方按位置上下文判断。

| 形态 | 判定（body=|close-open|，实体高度） |
|------|------|
| 长上影 | `上影 ≥ body×2` 且 `下影 < body` |
| 长下影 | `下影 ≥ body×2` 且 `上影 < body` |
| 纺锤线 | `上影 ≥ body×1.5` 且 `下影 ≥ body×1.5` 且 `body < 振幅/4` |
| 十字星 | `body / open < 0.005`（实体极小） |

## 优先级与覆盖规则

- **见顶阶梯（R01）内部**：对子顶 > 巨量见顶(≥4x升5)/第二波/涨停炸板 > 巨量异动。多信号触发只出最高一条。
- **离场阶梯（R02）内部**：急跌 > 死叉/破MA60 > 有效破10日线 > 跌破5日线/破趋势线 > 跌破10日线待确认。真死叉（5/13死叉+破55日线、5/10死叉）为强卖出档；5/13死叉站上55日线的回调型假死叉仅弱提醒（08-10 回测：假死叉后 T+5 反而微涨）。
- **跨阶梯**：R01（见顶）与 R02（离场）可同日并存——它们角度不同（量能形态 vs 破位），力度由各自的最高档决定，不再有"一条清仓一条减仓"的同角度矛盾。AI 在深度分析中综合判断。
- **买入共振强度档位**（预警页展示层）：对每只票触发的买入信号加权计分（A级=2、B级=1，参考级 R08/R11/R13/R14 不计入），分数映射为「弱观察(1) / 温和看多(2) / 较强看多(3) / 强烈共振(≥4)」。**量能维度**：若其中至少一条买入信号为"放量确认"（extraData 带 `volConfirmed:true`，R04/R05/R09/R10/R12 写入），档位 +1；全缩量不加级。
- **卖出信号严重度分级展示**（预警页展示层，2026-08-10）：R01/R02 阶梯的 extraData 带主信号 `sev`（沿用内部严重度 1~5）。**强卖出**（`isStrongSellAlert`：sev≥3，或 R03 等单信号卖出规则）才整卡染绿、摘买入共振徽章、按 CRITICAL/WARNING 排序；**弱提醒**（sev≤2：巨量异动/RSI超买新高/跌破5日线/站上55日线的5/13假死叉等）仅在行内以绿条展示，不染卡、不摘徽章、级别降为 INFO——弱提醒不应对买入共振有一票否决权。旧记录 extraData 无 `sev` 字段 → 保守按强处理。

## 辅助函数清单（services/alertRules.ts 顶部）

| 函数 | 用途 |
|------|------|
| `classifyCandle(k)` | 统一 K 线形态分类（长上影/长下影/纺锤线/十字星），R01/R06 共用 |
| `consecutiveUpDays(kLines, idx, n)` | 近 n 根连续收高，isUptrendRecently 连涨上下文用 |
| `isUptrendRecently(kLines, idx)` | 近期是否上涨趋势，R01 见顶形态位置上下文 |

均线交叉复用现有 `crossedAboveWithin`/`crossedBelowWithin`/`priceCrossedAboveWithin`/`priceCrossedBelowWithin`（within=2 容错窗口）。MA10 直接 `calculateMA(kLines, 10)`。

## 规则可信度分级（注入 AI prompt）

`RULE_RELIABILITY` 分 A 级（强信号）和 B 级（参考信号）：

- **A 级**：R01, R02, R04, R07, R10
- **B 级**：R03, R05, R06, R08, R09, R11, R12, R13, R14

`formatTriggeredRulesForAI()` 按此分级将触发规则格式化为「强信号 / 参考信号」两组注入分析师 prompt。`buyRuleWeight()` 按此分级给买入规则加权（A=2/B=1），供预警页买入共振强度档位计分。
