本工具做 A 股分析，但为规避监管查验，**任何对外可见处不得出现"股"这个字**——不是只禁"股票/选股/荐股"，是"股"字本身一律不出现（"个股""A股""股市""股价""股权"全算）。这是站点层面的合规自查，不是中转站风控（用户已不用中转站）。

## 适用范围（必须遵守）
页面标题、导航、更新日志（UpdateLog）、UI 文案、路由路径、git 提交信息、LLM 输出措辞——凡会渲染给用户或出现在提交记录里的文字，都不能有"股"字。

## 替代词（均不含"股"）
- 股票 / 个股 / A股 / 股市 / 股价 → **标的** / 标的资产 / 行情 / 品种 / 市场
  - "A股分析" → "标的分析" / "行情分析"
  - "个股详情" → "标的详情"
  - "自选股" → "自选标的" / "关注列表"
- 选股 → **筛选**（AI 选股功能对外一律称「AI 筛选」，路由 `ai-screen` 非 `ai-pick`）
- 荐股 → 避免，改"筛选/分析/参考"
- 涨停/跌停/炸板/连板 —— 不含"股"，可正常用

## 不受限（内部，不渲染给用户）
代码变量名、Prisma 模型/表名（`stocks`、`stockCode`、`StockFundamental`）、代码注释、API 路径（`/api/stock/...`）、内部记忆文件——这些不对外，保留语义化命名即可。新写用户可见文本时才需注意。

## LLM 输出
prompt 里给 AI 的阈值指引用中性事实陈述，不要大段"阈值→买卖结论"式荐股文本（即使现在不用中转站也保持）。注意 AI 生成内容里也别蹦出"股"字，必要时在 prompt 里显式约束措辞。

**How to apply**: 写任何用户可见中文时，脑内先把所有含"股"的词替换掉（最易漏的是"个股""A股"）。AI筛选功能细节见 [[ai-screen-feature]]。
