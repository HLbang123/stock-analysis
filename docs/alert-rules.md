# 预警规则说明

> 本文档是现有预警规则的人工参考说明。规则的**代码事实源**是 [services/alertRules.ts](../services/alertRules.ts)，**AI prompt 注入源**是 [services/deepAnalysisPrompt.ts](../services/deepAnalysisPrompt.ts) 的 `RULES_TABLE`。本文档供维护时阅读，若与代码不一致以代码为准。

共 **15 条**规则。卖出侧合并为两个**阶梯规则**（R01 见顶阶梯、R02 离场阶梯），同类信号在一个阶梯内按严重度择优，**杜绝"一条清仓一条减仓"的跨规则矛盾预警**。买入侧各信号独立触发（叠加确认，不做择优阶梯），预警页按触发数量+可信度聚合为「买入共振强度档位」。

## 卖出侧：两个阶梯规则

### R01 见顶阶梯

把所有"见顶/过热/量能出逃"信号合并到一个阶梯。一只票最多出一条见顶预警，主信号 = 触发里严重度最高者；**extraData 列出全部命中的子信号**（`{ main, triggered: [...] }`），供 UI 展示。

| 子信号 | 严重度 | 仓位 | 说明 |
|---|---|---|---|
| 对子顶 | 5 | 止盈减仓 | 高/收接近+上影+放量，双顶成型 |
| 巨量见顶 | 4 | 止盈减仓 | 量≥年最大×0.95 或 >5日最高×1.2 |
| 第二波见顶 | 4 | 止盈 | 近期量≥第一波高潮×0.9 |
| 长上影见顶+放量 | 4 | 止盈 | 上影≥实体×2 且 下影<实体，放量 |
| 涨停炸板 | 4 | 止盈减仓 | 触及涨停价后回落开板，追高风险大 |
| 长上影见顶 | 3 | 止盈 | 上影≥实体×2 且 下影<实体 |
| 跳空衰竭 | 3 | 止盈 | 跳空高开+小阳+双向影线 |
| 纺锤线见顶 | 3 | 止盈 | 上影≥实体×1.5 且 下影≥实体×1.5 且 实体<振幅1/4 |
| 长下影见顶 | 3 | 止盈 | 下影≥实体×2 且 上影<实体（连涨后=承接无力） |
| 涨停封板 | 2 | 追高谨慎 | 触及涨停并封住，注意明日开板风险 |
| 巨量异动 | 1 | 关注 | >5日均量×1.20 |

K线形态均要求"连续上涨后"上下文（三连阳 或 近3日涨幅>5%）。**位置分流**：长下影在连涨后=R01 顶部看空；在下跌末段+新低区=R07 底部锤子看多。同形态靠位置上下文分流到 R01/R07，互斥。

**涨停判定**：按代码前缀取涨跌幅比例——创业板(30x)/科创板(688)=20%、ST=5%、其余主板=10%；涨停价=`round(昨收×(1+比例),2)`。当日最高≥涨停价=触及涨停：收盘仍≥涨停价=`涨停封板`(2级，追高谨慎)，否则=`涨停炸板`(4级，止盈减仓)。`quote` 缺失时按主板10%兜底。

### R02 离场阶梯

把所有"破位/离场"信号合并到一个阶梯。一只票最多出一条离场预警，主信号 = 严重度最高者；**extraData 列出全部命中的子信号**。死叉清仓覆盖前序减仓。10日线为卖出主线（控回撤），买入仍看 5/13 金叉（R05）。

| 子信号 | 严重度 | 仓位 | 说明 |
|---|---|---|---|
| 急跌 | 5 | 先抛 | 单日跌幅>7% |
| 5/13死叉 | 4 | 清仓 | MA5下穿MA13；同步破55日线=下跌中继 |
| 5/10死叉 | 4 | 清仓 | MA5下穿MA10，短期反转 |
| 破趋势线+破MA60 | 4 | 清仓观望 | 破10日低点趋势线+破MA60，牛熊分界 |
| 有效跌破10日线 | 3 | 减仓70-80% | 连续两日收<MA10，破后未收回 |
| 放量离场 | 3 | 减仓 | 量比>2 + 价格破位 |
| 跌破5日线 | 2 | 减仓 | 收<MA5 + 放量 |
| 破趋势线 | 2 | 减仓 | 破10日低点趋势线+放量（未破MA60） |
| 跌破10日线待确认 | 1 | 适当减仓 | 当根收<MA10 且 前根收≥MA10（刚破） |
| MA5拐头 | 1 | 减仓30-40% | MA5连续2根下行 |
| 缩量破位 | 0 | 观望 | 连续两日收<MA5 + 缩量 |

**破位两段式**（用户决策）：实时系统"次日"数据未到，用"连续两日未收回"作有效破位的实时近似——当根跌破先提示「待确认」，下一根仍未收回站上才升级「有效跌破」。

### 其他卖出规则
- **R03 跌破55日线**：收盘下穿MA55，进入非多头区域，大势信号（非仓位指令）。
- **R04 妇联定律**：工业富联(sh601138)涨>8%，警惕科技板块大分歧。

## 买入侧（R05-R13）

买入信号各自独立触发，不择优；多个信号同时触发属**叠加确认**，预警页据此聚合出「买入共振强度档位」。

- **R05 5/13金叉**：MA5 上穿 MA13；放量+站上55日线→强买(A级)，否则谨慎(B级)。
- **R06 5/10金叉**：MA5 上穿 MA10；放量确认短线启动，与 R05 同时出现属多重确认。
- **R07 止跌企稳**：抛压释放(>10%) + 新低区锤子线(下影≥实体×2 + 下影>2% + 上影<1%) 或 十字星。
- **R08 RSI超卖**：RSI(6)<20 超卖；强下行趋势（MA20 下行 + 收盘破 MA20）中过滤不报，避免接飞刀。
- **R09 反包入场**：15日回调>5% + 涨≥5% + 收>98%近期高。
- **R10 黄金位反弹**：回调至0.382-0.618 + 涨>3% + 放量×1.2。
- **R11 箱体信号**：40日箱体突破(>3%+放量)优先，或60日箱体放量小阳吸筹。
- **R12 均线多头排列**：MA5>MA13>MA55 + 股价站上MA55，且多头排列刚刚形成（近2根内金叉或上穿MA55）；放量(量比≥1.2)确认多头格局，缩量为弱势多头需确认。
- **R13 站稳五日线加仓**：连续3日收盘站上MA5 + MA5上行 + 站稳刚刚形成（站稳前一日在MA5之下，避免上行趋势中每日重复触发）。量价配合：温和放量(量比1.0~1.8)量价配合好可加仓；暴量(>1.8)注意赶顶不追；缩量确认度一般。加仓信号。

## 参考级弱提醒（R14/R15）

筹码峰信号，B级参考，不参与买入共振硬聚合，仅作展示提示。

- **R14 筹码低位密集**：90%集中度<0.18 + 获利盘>60% + 主峰接近/低于现价，结构偏多。
- **R15 筹码高位套牢**：获利盘<40% + 主峰高于现价5% + 20日涨幅>15%，上方套牢盘重。

## 统一 K 线形态定义（`classifyCandle`）

用**影线/实体比**定义，长上影/长下影与纺锤线互斥。形态本身方向中性，是顶部还是底部信号由调用方按位置上下文判断。

| 形态 | 判定（body=|close-open|，实体高度） |
|------|------|
| 长上影 | `上影 ≥ body×2` 且 `下影 < body` |
| 长下影 | `下影 ≥ body×2` 且 `上影 < body` |
| 纺锤线 | `上影 ≥ body×1.5` 且 `下影 ≥ body×1.5` 且 `body < 振幅/4` |
| 十字星 | `body / open < 0.005`（实体极小） |

## 优先级与覆盖规则

- **见顶阶梯（R01）内部**：对子顶 > 巨量见顶/第二波/长上影+放量/涨停炸板 > 长上影/跳空衰竭/纺锤线/长下影见顶 > 涨停封板 > 巨量异动。多信号触发只出最高一条。
- **离场阶梯（R02）内部**：急跌 > 死叉/破MA60 > 有效破10日线/放量离场 > 跌破5日线/破趋势线 > 待确认/MA5拐头 > 缩量破位。死叉清仓覆盖前序减仓。
- **跨阶梯**：R01（见顶，适当减仓）与 R02（离场，可至清仓）可同日并存——它们角度不同（形态 vs 破位），力度由各自的最高档决定，不再有"一条清仓一条减仓"的同角度矛盾。AI 在深度分析中综合判断。
- **买入共振强度档位**（预警页展示层）：对每只票触发的买入信号加权计分（A级=2、B级=1），分数映射为「弱观察(1) / 温和看多(2) / 较强看多(3) / 强烈共振(≥4)」。**量能维度**：若其中至少一条买入信号为"放量确认"（extraData 带 `volConfirmed:true`，R05/R06/R09/R10/R11/R12/R13 写入），档位 +1；全缩量不加级。

## 辅助函数清单（services/alertRules.ts 顶部）

| 函数 | 用途 |
|------|------|
| `classifyCandle(k)` | 统一 K 线形态分类（长上影/长下影/纺锤线/十字星），R01/R07 共用 |
| `gapUpPercent(k, prevClose)` | 跳空高开百分比，R01 跳空衰竭用 |
| `consecutiveUpDays(kLines, idx, n)` | 近 n 根连续收高，isUptrendRecently 连涨上下文用 |
| `maTurningDown(maArr, idx, n)` | 均线连续 n 根下行，R02 MA5 拐头检测 |
| `isUptrendRecently(kLines, idx)` | 近期是否上涨趋势，R01 见顶形态位置上下文 |

均线交叉复用现有 `crossedAboveWithin`/`crossedBelowWithin`/`priceCrossedAboveWithin`/`priceCrossedBelowWithin`（within=2 容错窗口）。MA10 直接 `calculateMA(kLines, 10)`。

## 规则可信度分级（注入 AI prompt）

`RULE_RELIABILITY` 分 A 级（强信号）和 B 级（参考信号）：

- **A 级**：R01, R02, R04, R05, R07, R08
- **B 级**：R03, R06, R09, R10, R11, R12, R13, R14, R15

`formatTriggeredRulesForAI()` 按此分级将触发规则格式化为「强信号 / 参考信号」两组注入分析师 prompt。`buyRuleWeight()` 按此分级给买入规则加权（A=2/B=1），供预警页买入共振强度档位计分。
