## 1. 板三阴

**形态**：涨停后连续三根小阴线，第三根阴线为尾盘买点。

- T-3：涨停日，收盘约等于涨停价；非一字板（开盘未触及涨停）。
- T-2：红盘高开（open > T-3 收盘）、创新高（high > T-3 最高）、当日收小阴线（假阴也可）。
- T-1：小阴线，真阴（收盘低于 T-2 收盘）。
- T：小阴线，真阴（收盘低于 T-1 收盘）→ 买点。
- 小阴线口径：close < open，实体幅度 0.05% ~ 6.0%；第一根可假阴，第二、三根必须真阴逐日走低。
- 量能不要求（回测：量能递减无区分度，已移除）。

**买点/卖点**：T 日尾盘买入；次日冲高卖。

**回测**：

| 口径 | 样本 | 均涨 | 胜率 |
|---|---:|---:|---:|
| 第三阴收盘 → 次日最高 | 1390 | +2.77% | 87.8% |
| 第三阴收盘 → 次日收盘 | 1390 | — | 45.9% |

> 注：实体上限 5%→6% 后样本 +33%、最高胜率 89.1%→87.8%（2026-09-01 回测）。更早的十年严格基线仅 78 样本（最高 +2.72% / 92.31%）。

## 2. 龙首阴

**形态**：连续涨停后的第一根阴线；只做龙头/核心总龙头。

- 首阴位置：3 板起（3~5 板优先）；5 板及以上只做「假阴真阳」。
- 3~4 板：假阴真阳优先，真阴保留但降级。
- 长下影「分歧转一致」也视为首阴：下影 ≥ 收盘价 5%、收盘 > 当日振幅中点、收盘 > 昨收。
- 首阴不能收在跌停价附近。

**过滤**：

| 条件 | 值 |
|---|---|
| 首阴量比（/前 5 日均量） | ≤ 2.5 |
| 首阴换手率 | ≤ 45% |
| 首阴实体幅度 | ≤ 7% |
| 换手板门槛 | 连板中至少一个非一字板且换手 ≥ 8% |
| 连续一字板 | 默认排除 |

**买点/卖点**：首阴当日尾盘（firstYinToday）；次日冲高卖。

**回测（调参后口径：量比≤2.5、换手板门槛 8%）**：

| 口径 | 样本 | 均涨 | 胜率 | +2% 概率 |
|---|---:|---:|---:|---:|
| 首阴收盘 → 次日最高 | 169 | +4.67% | 81.7% | 72.8% |

## 3. 双龙

**形态**：首板非一字实体板，次日连续涨停（二板）。

- 首板：必须实体板（非一字），不卡实体大小 / 60 日突破 / 放量。
- 二板：连续第二个涨停；只认「恰好二板」（二板前一天不能也是涨停）。
- 二板封板时间先后：**人工比对**，不程序过滤。
- 二板若为一字板：加分，不作硬性剔除。

**方式一 · 二板打板**：买点 = 二板接近封板时以涨停价买入；退出 = 第三天开盘价。

| 口径 | 样本 | 均涨 | 胜率 |
|---|---:|---:|---:|
| 二板 → 次日开盘 | 3916 | +3.06% | 69.25% |
| 二板 → 次日最高 | 3916 | +7.17% | 88.56% |
| 十年口径 → 次日最高 | 5200 | +7.17% | 89.6% |

**方式二 · 回踩买入**：二板后 1~3 个交易日内回踩 5 日线且缩量（量 < 前 5 日均量 × 0.8）；退出 = T+1 最高价。

| 口径 | 样本 | 均涨 | 胜率 |
|---|---:|---:|---:|
| 回踩 → 次日开盘 | 1019 | -1.66% | 28.85% |
| 回踩 → 次日最高 | 1019 | +2.33% | 75.17% |

> 二板打板样本未过滤「二板一字板买不进」，当前结果偏乐观。

## 4. 龙四阴

**形态**：涨停首板（非一字、放量、接近 20 日新高）后连续四根阴线，第 4 阴收盘买。

| 位置 | 条件 |
|---|---|
| T-4 | 涨停：封板、非一字、首板（前一日非涨停） |
| 放量 | 涨停量 ≥ 前 10 日均量 × 1.5 |
| 位置 | 涨停收盘 ≥ 前 20 日最高 × 0.95 |
| T-3 | 第 1 阴：高开（open > 涨停收盘）、实体 0.05% ~ 8% |
| T-2 / T-1 | 第 2、3 阴：收阴（close < open），不要求逐日走低 |
| T | 第 4 阴：收阴 → 尾盘关注 |

**买点/卖点**：第 4 阴收盘买入；次日冲高卖（不格局）。

**回测（主板近 3 年）**：

| 口径 | 样本 | 均涨 | 胜率 |
|---|---:|---:|---:|
| 次日开盘 | 606 | +0.13% | 48.8% |
| 次日最高 | 606 | +2.61% | 91.75% |
| 次日收盘 | 606 | +0.81% | 65.2% |

## 5. 仙人指路

**形态**：试盘日长上影（冲高回落）后，确认日反包上影；试盘日当天不买，确认日尾盘买。

**试盘日（T0，只观察不买）**：

| 条件 | 口径 |
|---|---|
| 长上影 | 上影 ≥ 实体 1.2 倍，且上影幅度 ≥ 1.5% |
| 小实体 | 实体幅度 ≤ 2% |
| 收红 | 收盘相对昨收涨幅 0 ~ 5% |
| 放量 | 量比 ≥ 前 5 日均量 1.2 倍 |
| 无下影 | 下影 ≤ 1% |
| 振幅 | 振幅 ≤ 5% |
| 收盘位 | 收盘在当日振幅下半区（≤ 0.45） |
| 低位 | 60 日涨幅 ≤ 30% |
| 不破昨收 | 最低价 ≥ 昨收 |

**确认日（T1）**：

| 条件 | 口径 |
|---|---|
| 反包上影 | 现价 ≥ 试盘日收盘 + 上影 × 40% |
| 收高位 | 现价收位 ≥ 70%（扫描时点现价视作收盘价计算） |
| 不高开 | 确认日高开 ≤ 1% |

**买点/卖点**：确认日（T1）尾盘买入；次日（T2）冲高卖，不格局。

**回测（主板近 3 年，档 2 大样本版）**：

| 形态 | 样本 | 最高胜率 | 最高均涨 | 收盘胜率 |
|---|---:|---:|---:|---:|
| 仙人指路 | 2497 | 93.6% | +3.42% | 69.2% |

分年最高胜率：2023 89.8% / 2024 96.9% / 2025 88.5% / 2026 89.6%。

## 口径与局限

- 主口径「次日最高价卖出」是理想值，实盘难抓最高点；未计手续费、滑点。
- 双龙打板十年口径未做「二板一字板买不进」可成交过滤，偏乐观。
- 板三阴存在两版口径：十年严格基线 78 样本（92.31%），实体上限放宽至 6% 后 1390 样本（87.8%）。
- 仙人指路「收位」用扫描时点现价计算；确认日盘中反包即可入选，收盘是否收高位由人工尾盘把关。
- 退潮期 / 核按钮环境不拦截候选，仅在前端提示风险。
