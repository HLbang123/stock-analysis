# 龙首阴策略 · 接入可行性（买入侧）

状态：探索稿 + 纯逻辑原型（未接入 UI/API，未提交）

## 结论

可以接入。这个策略比上一版「涨停 + 三连阴」更聚焦，本质是：

> 在 3~5 连板的龙头里，等第一根阴线出现，次日竞价或快速拉升时买入；卖出侧不管。

现有 AI 筛选定位正好匹配：只做买入建议，不做卖出管理。日线部分可用本地 daily_bars 全市场扫；龙头识别和情绪退潮可用现有 fuyao 涨停池 / 连板天梯 + market_breadth。

## 规则翻译

### 1. 龙头范围

- 只做主板，排除创业板、科创板、北交所、ST/退市。
- 龙头近似定义：全市场连板高度最高的一批，或涨停池中连板数最高的核心标的。
- 首阴出现位置：首阴前连续涨停板数量必须在 3~5 板。

### 2. 连板质量

- 换手板优先：涨停日不是一字板，且换手率不低于阈值（暂定 5%）。
- 连续加速一字板次之：可以观察，但优先级低；若连续一字板且无换手，可配置为直接跳过。

### 3. 首阴定义

- 首阴 = 连板后第一根阴线（close < open）。
- 优先「假阴真阳」：close < open，但 close 仍高于昨日收盘。
- 真阴（close < 昨日收盘）也识别，但优先级低于假阴真阳。
- 首阴不能收在跌停价附近（核按钮级大阴线直接排除）。

### 4. 量能

- 首阴量能允许放大，但相对前 5 日均量不能暴增（暂定上限 3 倍）。
- 首阴换手率暂设上限 45%，过高视为筹码散得过快。

### 5. 情绪环境

- 退潮期 / 核按钮环境慎用或不用。
- 判定依据：跌停家数、炸板率、市场最高连板高度、现有 market_regime。
- 退潮期默认不输出买入候选；进攻/中性环境才输出。

### 6. 买点（输出为三种信号）

- firstYinToday：今天盘中已构成首阴，适合预判型尾盘/次日操作。
- firstYinYesterday：昨天已首阴，今天竞价或 9:30 后快速拉升时介入。
- 打板：由使用者自行按涨停价挂单，系统只提示候选强度，不代挂单。

## 数据依赖

- daily_bars：连板识别、首阴、量比、换手率。库内已有，够用。
- fuyao 涨停池 / 连板天梯：实时龙头与连板高度，已有 /api/fuyao/limit-up 与 /api/limit-up。
- market_breadth：跌停家数、涨停家数、炸板数，用于退潮期判定，已有。
- 无需历史分时数据：龙首阴不要求分时斜率/炸板回封判定，比上一版轻。

## 已确认口径（2026-08-27 问答）

1. 龙头候选池：按连板高度分层，3~5 板内全部主板标的，不设固定 N。
2. 连板位置：严格 3~5 板。
3. 首阴类型：假阴真阳优先，真阴保留但降级。
4. 一字板：连续一字板保留但降为低优先级；可配置直接剔除。
5. 量能口径：首阴量比 ≤ 前 5 日均量 3 倍，且换手率 ≤ 45%。
6. 退潮期：直接不输出买入候选。
7. 买点：T日尾盘输出 firstYinToday；T+1早盘对同一批候选做轻量刷新，输出 firstYinYesterday；打板只给参考价，不代挂单。
8. 运行方式：两阶段跑——T日尾盘重跑并落库，T+1早盘复用快照做竞价/快速拉升刷新，不重新全市场扫。
9. 尾盘数据：允许用实时行情合成今日 K 线，作为首阴当日判定。
10. 回测口径：首阴收盘价买入、次日打板价买入两种入口，统一统计次日最高点收益。
11. 新增盘口过滤（仅实时，不回测）：2板后次日（3板当天）9:25集合竞价必须已是涨停价，否则视为烟雾弹剔除。
12. 双龙战法（仅实时，不回测）：二板要比一板封板时间更早；二板一字板加分，不是一字板也保留。

## 参数调优结果（2026-08-27，目标=次日最高≥+2%概率）

- 基线（旧默认）：n=697，+2%概率 67.0%，平均 +4.18%，胜率 77.2%。
- 推荐平衡参数：maxVolumeRatio=2.0，minTurnoverRate=8，其余不变。
  - n=169，+2%概率 72.8%，平均 +4.67%，胜率 81.7%。
- 更严格参数：maxVolumeRatio=2.0，minTurnoverRate=10。
  - n=124，+2%概率 73.4%，平均 +4.85%，胜率 81.5%。
- 结论：量比上限从 3 收到 2 明显提升质量；换手板门槛 8% 是样本与胜率的平衡点，10% 更纯但样本少。
