# 预警小工具 · 使用说明

工具按 **14 条技术形态规则** 逐只检测，触发就亮预警卡片；同时提供 AI 对话、深度分析、波段评分、每日 AI 筛选、全市场扫描、大盘情绪面板和复盘统计。

功能地图：

| 页面 | 干什么用 |
|------|----------|
| **预警**（首页） | 自选清单的买卖信号检测，买红卖绿，买入共振聚合 |
| **大盘** | 市场宽度、涨停情绪、行业强度、估值分位、北向、融资融券 |
| **自选** | 管理自选清单：搜索添加、持仓截图识别、分组管理 |
| **AI 分析** | 波段评分、深度分析、AI 对话、历史分析 |
| **扫描** | AI 筛选（每日自动）+ 全市场扫描（手动条件组合） |

## 一、三分钟快速上手

### 第 1 步：登录

打开网址，输入**访问口令**（找把工具分享给你的人要）。一次输入 **30 天有效**，不用每次登录。

### 第 2 步：添加自选

进入「自选」页，两种方式任选：

- **搜索添加**：在搜索框输入名称或代码，点结果即加入。
- **截图识别**：点搜索框右侧的相机图标，上传券商 App 的持仓截图，自动识别代码，确认后一键全部加自选（还能顺手选个分组）。

### 第 3 步：看预警

回到首页「预警」，点上方 **「检查预警」** 按钮，工具会逐只检测你的自选：

- **红色** = 买入信号，**绿色** = 卖出信号。
- 同一天触发多个买入信号时，会折叠成 **「买入共振 · N 条」**，并给出强度档位（弱观察 → 温和看多 → 较强看多 → 强烈共振）。
- 点任意卡片可跳到该标的的详情页。

> 预警不会自动刷，想看最新信号就再点一次「检查预警」。

### 第 4 步（可选）：配置 AI

以下功能用你自己的大模型 API：**AI 对话、深度分析、波段评分**。
以下功能服务器统一跑，**不需要任何配置**：每日 AI 筛选、周报。

配置方法（只需一次）：

1. 进入「AI 分析」页，点配置入口（齿轮/配置按钮），「添加 API 配置」。
2. 填三项：**API Key**、**Base URL**（如 `https://api.deepseek.com/v1`）、**模型名**（如 `deepseek-chat`）。没有 Key 就去大模型平台注册一个，按量计费，日常分析花费很小。
3. 可以点「获取模型列表」验证填得对不对，保存后即可使用。
4. 支持保存多套配置，随时切换。

### 第 5 步（推荐）：开启云同步

首页右上角「同步」→「开启云同步」。之后换手机/换电脑，用**配对码**即可把自选、分组、AI 配置、分析历史全部恢复到新设备（详见第五章）。

## 二、页面详解

### 2.1 预警（首页）

**怎么用**：点「检查预警」→ 等检测跑完 → 按卡片严重程度排序展示。

**卡片怎么读**：

- 整卡染红 = 有买入信号；整卡染绿 = 有**强卖出**信号（急跌破位级别）。
- 只有**轻微提醒**（巨量异动、跌破5日线这类）时不会染绿整卡，只在行内显示一条绿条——它不该一票否决同日的买入共振。
- 买入信号按可信度加权聚合成**共振档位**：弱观察（1 条）→ 温和看多 → 较强看多 → 强烈共振（4 条以上）；带放量确认的信号会升一档。
- 信号消失后卡片沉底并显示划痕线，方便区分「还在触发」和「已失效」。

**顶部几个按钮**：

- **复盘**：周报 / 胜率复盘（详见第四章）。
- **同步**：多设备云同步。
- **分组筛选**：预警列表可按自选分组过滤，只看某一组的信号。
- **左上角汉堡菜单**：更新日志、鸣谢、**规则说明**（14 条规则的完整含义和触发条件）。

### 2.2 大盘

开盘前/收盘后看市场整体状态，共八个面板：

| 面板 | 看什么 |
|------|--------|
| 市场宽度温度计 | 涨/平/跌家数、涨停跌停数 |
| 大势温度 | 处于多头区间的标的占比 |
| 行业强度榜 | 强势行业排行（资金在哪个方向） |
| 指数估值分位 | 主要指数估值在历史中的位置 |
| 北向资金 | 外资净流入/流出 |
| 融资融券 | 两融余额与净变化 |
| 涨停情绪 | 涨停/连板/炸板数据（盘后更新） |
| 行业涨跌幅排行、热度排行 | 当日行业表现与热门方向 |

> 注意：指数行情是实时的，但市场宽度、涨停情绪等统计类数据是**盘后更新**的，页面上标注了所属交易日，盘中看到昨天的是正常现象。

### 2.3 自选

- **搜索添加**：支持名称/代码模糊搜索，ETF 也支持。
- **持仓截图识别**：相机图标 → 上传截图 → 开始识别 → 一键全部加自选（可指定分组，也可临时新建分组）。
- **分组管理**：建组/改名/删除，把标的移入指定组，按组筛选展示。不分组的标的一直在「未分组」。
- **持仓占比**：可给每只标的填仓位占比，AI 分析时会参考。
- **均线交叉徽标**：卡片上直接显示金叉 / 死叉 / 即将金叉，不用点进去看。

### 2.4 AI 分析

先在顶部选择标的（可直接搜索，不用先加自选），然后：

**波段评分**（盘中工具，仅在交易时段可用）

- 给出 **买点分 / 卖点分**（各 0–100）：确定性因子先算出来，AI 再微调。
- 买点分高 = 分时位置适合低吸；卖点分高 = 冲高衰竭适合高抛。
- 「因子分解」默认折叠，想研究每个因子的打分时点开看。
- 非交易时段或分时数据不足会提示降级，这是正常的——它本质是盘中工具。

**深度分析**（全面体检，耗时较长）

- 多空双方法庭式辩论 + 裁决，输出：建议方向、目标价区间、止损位、建议仓位、信心指数。
- 仓位建议会联动大盘强弱。
- **中断不怕**：刷新/锁屏/断网后重进，会提示「继续生成」，从断点接着跑。
- 有历史分析记录的标的，会显示「历史战绩条」（这类建议过去的胜率），帮助校准信任度。

**AI 对话**

- 随便问：行情、K 线、排名、大盘、异动原因、涨停池、基金持仓，它会自己查数据再回答。
- **多标的对比**：最多加 5 只，横向对比行情/基本面/筹码。
- 「附带分析结论」开关：把当前标的的分析结果一并带入对话上下文。
- 回复逐字实时输出，「思考过程」可折叠。
- 对话会一直保留，直到你主动点「新对话」。

**历史分析**：底部切到「历史分析」，回看所有波段评分和深度分析记录。

### 2.5 扫描

**「AI 筛选」标签页**

- **每日 18:30 后服务器自动运行**，全员共享同一份结果，打开即看，不需要个人 AI 配置。
- 当前策略视角：
  - **趋势优选**：强势趋势 + 低波入场，偏进攻。
- 流程是：全市场硬筛 → 多因子打分 → AI 横向重排 → 风险约束，每策略取前列标的。
- 结果支持按综合分/涨跌幅点击排序；「策略说明」「AI 视角」默认折叠，想了解逻辑再点开。

**「全市场扫描」标签页（手动）**

自由组合条件，点查询出结果（上限 200 只）：

| 条件 | 说明 |
|------|------|
| RPS 排名 | 周期多选（20/60/120/250 日），筛全市场强度前列 |
| 5/13 金叉 | 窗口多选：即将金叉 / 近 N 日，可自定义 N |
| 55 日线上方 | 趋势过滤（价格站在 55 日线上方才入选） |
| ROE 下限 | 基本面质地过滤 |
| 流通市值下限 | 过滤小市值 |
| RSI 过滤 | 周期 6/12/24 日可选，上下限自设，筛超卖或超买 |
| 板块 | 搜索行业名直达（如"半导体"），可选一级/二级行业；也可按主板/创业板/科创板/北交所过滤 |

结果表中 **RPS / 最新价 / 日涨跌幅可点击排序**，「一键加自选」时可选择目标分组。

### 2.6 标的详情页

从预警卡片、自选列表或搜索结果点进去：

- **顶部**：实时行情 + RPS 徽章（20/60/120/250 日强度排名）+ 趋势状态 + 行业/概念标签。
- **K 线图**：叠加支撑压力位虚线、触发的规则标记。
- **分时图**：交易时段可用，预警标记智能定位（见顶信号标在最高价附近，见底信号标在最低价附近）。
- **基本面速览 + 资金流向**：主力/大中小单结构 mini 图。
- **支撑压力位**：结构位 + 黄金分割回撤。
- **筹码分布**：筹码峰、平均成本、获利盘比例。
- **历史预警**：该标的触发过的所有规则记录。
- 右上角可「添加自选」。

## 三、预警规则速查

共 **14 条规则**。买入侧各信号独立触发、叠加确认；卖出侧合并为两个阶梯规则（见顶/离场），一只标的同时最多各出一条，杜绝"一条清仓一条减仓"的矛盾预警。

| 方向 | 规则 | 一句话 |
|------|------|--------|
| 卖出 | R01 见顶阶梯 | 对子顶/巨量见顶/长上影/炸板等，按严重度只出最高一条 |
| 卖出 | R02 离场阶梯 | 急跌/死叉/破位等，按严重度阶梯减仓至清仓 |
| 卖出 | R03 跌破 55 日线 | 进入非多头区域，大势信号 |
| 买入 | R04 5/13 金叉 | 放量 + 站上 55 日线 = 强买 |
| 买入 | R05 5/10 金叉 | 放量确认短线启动 |
| 买入 | R06 止跌企稳 | 抛压释放后新低区锤子线/十字星 |
| 买入 | R07 RSI 超卖 | 强下跌趋势中会过滤，不接飞刀 |
| 买入 | R08 反包入场 | 回调后放量反包突破 |
| 买入 | R09 黄金位反弹 | 回调至黄金分割位放量反弹 |
| 买入 | R10 箱体信号 | 箱体突破优先，或箱体吸筹 |
| 买入 | R11 均线多头排列 | 多头排列刚形成 + 放量 |
| 买入 | R12 站稳五日线加仓 | 连续 3 日站上 MA5 且温和放量 |
| 参考 | R13 筹码低位密集 | 结构偏多（弱提醒，不计入共振） |
| 参考 | R14 筹码高位套牢 | 上方套牢盘重（弱提醒，不计入共振） |

- 信号分 **A 级（强信号）/ B 级（参考）**：A 级 = R01/R02/R04/R06/R07，其余为 B 级。买入共振计分时 A 级权重更高。
- 完整判定条件见首页汉堡菜单 →「规则说明」。

## 四、复盘体系

首页「复盘」按钮，两个标签页：

| 标签 | 内容 | 更新时点 |
|------|------|----------|
| **周报** | 本周速览（涨跌比/筛选胜率/预警/涨停等）| 周五晚 |
| **胜率复盘** | 三个子标签：深度分析 / AI 筛选 / 预警规则 | 持续累积 |

**胜率复盘怎么看**：

- **深度分析**：各建议方向的历史胜率（T+5/10/20）、目标/止损命中率、月度趋势、置信度校准。
- **AI 筛选**：策略排行、因子有效性、AI 重排的增益对比。
- **预警规则**：每条规则的实战胜率健康度监控。
- 样本不足 10 的数据会**灰显"样本少，仅供参考"**——小样本胜率波动大，别当真。
- 胜率需要 T+N 天回填，刚发生的信号暂时没有成绩，属正常。

## 五、多设备云同步

解决"换手机/换电脑数据全丢"。自选、分组、持仓、AI 配置、分析历史都加密备份在服务器。

**第一台设备**：首页「同步」→「开启云同步」，一键完成，无感。

**添加新设备**：

1. 旧设备上：同步 →「添加设备」→ 显示一个 **6 位配对码**（10 分钟内有效）。
2. 新设备上：同步 → 输入配对码 → 数据自动恢复。

**日常**：开启后自动同步（改动后约 15 秒上传，每分钟检查远端更新），也可手动点「立即同步」。

## 六、数据时点（重要，避免误解）

| 数据 | 更新时点 |
|------|----------|
| 行情、分时、K 线、预警检测 | 实时（点「检查预警」那一刻拉最新） |
| 日线统计数据（RPS、市场宽度等） | 交易日 16:00 后入库 |
| AI 筛选 | 交易日 18:30 后 |
| 周报 | 周五 18:00 |
| 涨停情绪 | 盘后（盘中看到的是上一交易日的） |

盘中看大盘页时，统计类面板标注了所属交易日（T-1 是昨天），不是 bug。

## 七、常见问题

**Q：为什么 AI 对话/深度分析要我配 Key，AI 筛选却不用？**
A：AI 筛选、周报由服务器统一运行，全员共享；而对话、深度分析、波段评分是为你个人实时跑的，用你自己的大模型配置，用多少花多少，日常花费很小。

**Q：点波段评分提示"需在交易时段使用"？**
A：它基于当日分时数据计算，只有交易日 9:30–15:00 可用，闭市后会降级提示，属正常。

**Q：深度分析跑到一半网断了/锁屏了？**
A：重新进入会提示「继续生成」，从断点接着跑，不重复扣费。

**Q：预警是自动推送的吗？**
A：不是推送制。打开首页点「检查预警」即拉最新行情全量检测，建议盘中和收盘前各点一次。

**Q：换了手机，自选全没了？**
A：提前开过云同步的话，新设备输配对码即可全部恢复。没开过就只能重加——所以强烈建议到手先开同步。

**Q：周末/节假日数据不更新？**
A：对，所有统计都按交易日跑，非交易日看到的是上个交易日的数据。

**Q：AI 筛选的结果几天验证一次？**
A：系统对每个入选标的做 T+1/T+5/T+20 的收益回填，在「复盘 → 胜率复盘 → AI 筛选」里看策略的真实胜率，别只看当天的名单。
