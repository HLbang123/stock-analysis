# 短线策略库（正式稿）

> 状态：规则已定稿，十年基线回测已完成，龙首阴已完成一轮参数调优。
> 本文件是当前唯一正式策略口径；后续接 UI / 回测 / 调参都以此为准。

- 三套策略**互相独立**，分开回测、分开展示：
  1. 涨停 + 三连阴
  2. 龙首阴
  3. 双龙战法
- 所有策略只输出**买入候选**，不管理卖出。
- 只做沪深主板：600 / 601 / 603 / 605 / 000 / 001 / 002 / 003。

- 退潮期 / 核按钮环境默认不输出候选。
- 历史回测只代表日线口径；盘口实时过滤不回测，接入时作为实时条件执行。

## 1. 策略一：涨停 + 三连阴

### 1.1 形态定义

以「第三根阴线」为买入日 T：

| 位置 | 条件 |
|---|---|
| T-3 | 涨停日：收盘约等于涨停价；非一字板（开盘价未触及涨停） |
| T-2 | 红盘高开：open > T-3 收盘；创新高：high > T-3 最高；当日收小阴线 |
| T-1 | 小阴线，真阴（收盘低于 T-2 收盘） |
| T | 小阴线，真阴（收盘低于 T-1 收盘） |
| 量能 | 三根阴线逐日缩量：T-2 量 > T-1 量 > T 量（首阴可放量，不要求低于涨停日量） |

### 1.2 小阴线口径

- close < open。
- 实体幅度 0.05% ~ 3.0%。
- 三根都必须是真阴：收盘价低于前一日收盘价，排除假阴。

### 1.3 买点与退出

- 买点：T 日尾盘买入。
- 实时过滤：T 日尾盘 5 分钟应横盘或小幅下跌，不能快速拉升。
- 回测退出口径：次日最高价。

### 1.4 十年回测结果

| 口径 | 样本 | 平均 | 胜率 | 中位 |
|---|---:|---:|---:|---:|
| 第三阴收盘 → 次日开盘 | 78 | -0.10% | 55.13% | +0.07% |
| 第三阴收盘 → 次日最高 | 78 | +2.72% | 92.31% | +1.78% |

结论：信号稀少但次日冲高概率高；次日开盘基本无溢价，不适合无脑卖开盘。

## 2. 策略二：龙首阴

### 2.1 形态定义

- 连续涨停后出现第一根阴线，称为龙首阴。
- 3~4 板后首阴：假阴真阳优先，真阴保留但降级。
- 5 板及以上首阴：只做假阴真阳（收盘不低于昨日收盘）。
- 日内洗盘不一定是阴线：长下影的「分歧转一致」也视为龙首阴，如地天板式长下影。
- 首阴不能收在跌停价附近。

长下影分歧转一致的量化口径：

- 下影线 ≥ 收盘价 5%。
- 收盘价高于当日振幅中点。
- 收盘价高于昨日收盘。
- 量能、换手、退潮期过滤照旧。

### 2.2 过滤条件

| 条件 | 当前值 |
|---|---|
| 首阴量比 / 前5日均量 | ≤ 2.0 |
| 首阴换手率 | ≤ 45% |
| 首阴实体幅度 | ≤ 7% |
| 换手板门槛 | 连板中至少有一个非一字板，且换手率 ≥ 8% |
| 连续一字板 | 默认排除（受换手板门槛影响） |
| 高位板 | 5板及以上只做假阴真阳 |

### 2.3 买点

- T 日尾盘：输出 firstYinToday（当日构成首阴）。
- T+1 早盘：对昨日候选做刷新，输出 firstYinYesterday。
- T+1 实时过滤：9:25 集合竞价必须是涨停价，否则视为烟雾弹剔除。

### 2.4 十年回测结果

原始基线（量比≤3、换手板门槛5%）：

| 口径 | 样本 | 平均 | 胜率 | 中位 |
|---|---:|---:|---:|---:|
| 首阴收盘 → 次日最高 | 714 | +4.05% | 76.75% | +4.08% |
| 首阴收盘 → 次日开盘 | 714 | -1.88% | 27.73% | -1.62% |

调参后推荐口径（量比≤2、换手板门槛8%）：

| 口径 | 样本 | 平均 | 胜率 | +2%概率 |
|---|---:|---:|---:|---:|
| 首阴收盘 → 次日最高 | 169 | +4.67% | 81.7% | 72.8% |

结论：钱在盘中冲高，不在开盘；3~4板与换手板表现更稳，5板以上需假阴真阳过滤。

## 3. 策略三：双龙战法

### 3.1 首板条件（2026-08-27 定稿）

- 首板必须是实体板：非一字板。
- 不卡实体大小、60 日突破与放量。

### 3.2 二板条件

- 二板为连续第二个涨停。
- 只认「恰好二板」：二板前一天不能也是涨停（避免把 3 板及以上识别为双龙）。
- 实时过滤：二板封板时间必须早于首板封板时间。
- 二板若为一字板，加分但不作硬性剔除。

### 3.3 买入方式一：二板打板

- 买点：二板接近封板时以涨停价买入。
- 退出：第三天开盘价。

### 3.4 买入方式二：回踩买入

- 二板后 1~3 个交易日内，回踩到 5 日线附近。
- 回踩日缩量：成交量 < 前 5 日均量 × 0.8。
- 退出：T+1 最高价。

### 3.5 十年基线结果

| 买入方式 | 样本 | 开盘退出 | 最高退出 |
|---|---:|---:|---:|
| 二板打板 | 3916 | +3.06%，胜率69.25% | +7.17%，胜率88.56% |
| 回踩买入 | 1019 | -1.66%，胜率28.85% | +2.33%，胜率75.17% |

重要提示：二板打板的 3916 个样本尚未过滤「二板一字板买不进」和「二板早于首板」实时条件，当前结果偏乐观。正式接入前需要补一版可成交口径回测。

## 4. 统一数据依赖

- 本地 daily_bars：日线形态、连板、量能、换手率。
- stocks：名称、状态、板块过滤。
- 涨停池 / 连板天梯：实时龙头、连板高度、封板时间。
- market_breadth：涨停、跌停、炸板、市场情绪。
- 当日分时：尾盘横盘、9:25 竞价、快速拉升确认。

## 5. 接入方案

- 位置：AI 筛选内新增短线策略入口。
- 运行方式：两阶段。
  - T 日尾盘：跑出当日候选并落库。
  - T+1 早盘：只刷新昨日候选，执行 9:25 涨停、双龙封板时间、快速拉升等实时过滤。
- 输出：候选列表 + 命中条件，不输出买卖建议措辞。

## 6. 回测统一口径与局限

- 最高价退出 = 理想值，实盘难抓。
- 未计手续费、滑点。
- 涨停+三连阴样本少；双龙打板样本未做可成交过滤。
- 实时盘口过滤不回测，只作为上线后的硬条件。
